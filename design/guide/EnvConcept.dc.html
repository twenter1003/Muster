탭 · 환경 구성

“환경 구성”이 대체 뭔가요?

에이전트가 코드를 돌릴 실행 환경(Docker)입니다. 도커를 몰라도 됩니다 — 언어 · 프레임워크 · 데이터베이스를 고르면 Muster가 설정 파일을 대신 만들어 줍니다.

1

고른다

Python + FastAPI + PostgreSQL 처럼 클릭으로 고릅니다.

2

검사한다

Policy Gate가 위험한 설정(외부 포트 개방 등)을 자동으로 잡아냅니다.

3

승인한다

검사를 통과하면 승인하고 실행이 활성화됩니다.

4

빌드된다

GitHub Actions에서 실제로 이미지가 만들어지고 상태가 갱신됩니다.

상태(build_status)가 뜻하는 것

draft 작성 중 · approved 승인됨 · running 빌드 중 · succeeded 완료 · failed 실패

Policy Gate란

“이 설정이 안전한가”를 자동 검사하는 관문입니다. 걸리면 무엇이 왜 걸렸는지 화면에 이유가 나오고, 고치면 다시 통과합니다.
